# Domain Docs

本仓库采用 single-context 布局。

## 阅读规则

调查代码前，阅读根目录的 `GLOSSARY.md`，以及 `docs/adr/` 中与当前任务相关的架构决策记录。

这些文档按需要建立。文件尚未建立时，直接继续任务。通过 `domain-modeling` 明确领域术语或架构决定时，再创建对应文档。

## 文件位置

| 内容 | 路径 |
| --- | --- |
| 项目领域词汇表 | `GLOSSARY.md` |
| 架构决策记录 | `docs/adr/NNNN-主题.md` |

## 使用术语与决策

在任务标题、重构建议、问题假设和测试名称中，采用 `GLOSSARY.md` 定义的术语。

遇到尚未定义的概念时，先核对项目已有名称；确有缺失时，将该概念交给 `domain-modeling` 明确。

拟议改动与已有架构决策冲突时，明确指出 ADR 编号、冲突内容和重新评估理由。
